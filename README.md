# Digital පංචිකාවත්ත

A mobile application designed to digitize and modernize the traditional Sri Lankan automobile spare parts market, originally centered around physical markets like Panchikawatta. Developed using Flutter and Dart, the app supports both Android and iOS platforms and integrates features such as AI chat, real-time communication, secure transactions, and location-based services.

## 📱 Overview

Digital පංචිකාවත්ත offers a centralized and intelligent solution for the purchase and sale of vehicle spare parts. The app bridges the gap between traditional vendors and digital consumers, offering convenience, accessibility, and efficiency.

---

## 🚗 Key Features

- **User Authentication & Account Management**
- **Product Listings** by sellers with images, descriptions, and categories
- **Search & Filter** spare parts by brand, condition, and category
- **Cart & Secure Checkout** with card and cash-on-delivery support
- **Order History & Tracking** via user dashboard
- **AI Chatbot & Real-Time Messaging** for support and buyer-seller communication
- **Nearby Service Locator** using Google Maps API
- **In-app Language Translation** between Sinhala and English
- **Smart Product Recommendations** based on user preferences

---

## 🧠 Technologies Used

- **Flutter** - Cross-platform UI toolkit
- **Dart** - Programming language used by Flutter
- **Firebase** - Authentication, Firestore database, cloud storage
- **Google Maps API** - Location-based services
- **GitHub/Git** - Version control and collaboration
- **Figma** - UI/UX design
- **Visual Studio Code** - Main IDE
